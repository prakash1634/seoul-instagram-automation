# Seoul Instagram Automation

A web-based Instagram marketing and automation dashboard for Korean / Seoul fashion content.

The project is designed to manage the complete content workflow from one place:

**Campaign → Fashion Content → Caption & Hashtags → Instagram Post/Reel → Scheduling → Analytics**

---

## 🚀 Project Overview

**Seoul Instagram Automation** is a browser-based marketing dashboard built for Instagram fashion creators and brands.

The main focus is:

- Korean fashion
- Seoul fashion aesthetics
- Korean-style dresses
- AI-assisted fashion content
- Instagram posts
- Instagram Reels
- Captions
- Hashtags
- Campaign management
- Publishing automation
- Marketing workflow
- Analytics

The dashboard is designed to work in Chrome on desktop and mobile.

---

# ✨ Main Features

## 1. Instagram Connection

The dashboard supports connecting an Instagram professional account through the official Meta / Instagram authorization system.

The system is designed to use official API access instead of unofficial login automation or browser scraping.

Supported workflow:

```text
Dashboard
   ↓
Connect Instagram
   ↓
Instagram Authorization
   ↓

   ↓

   ↓
Publish Content
